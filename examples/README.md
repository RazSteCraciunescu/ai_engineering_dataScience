# Optional framework examples

The production-style core deliberately uses a small dependency set. These examples show how the same artifacts can be extended with common course and industry tools without making every reviewer install several gigabytes of packages.

| Directory | Coverage |
| --- | --- |
| `foundations/` | Arrays, vectors, matrices, tensors, masks, distributions and gradient descent |
| `deep_learning/` | A NumPy neural network plus Keras/TensorFlow and PyTorch examples |
| `ml/` | XGBoost classification |
| `nlp/` | Hugging Face inference and BERT/ALBERT/RoBERTa/GPT distinctions |
| `genai/` | Ollama, LangChain, LlamaIndex, CrewAI and Stable Diffusion |
| `vector_databases/` | Chroma and Qdrant |
| `mlops/` | MLflow, Weights & Biases and Langfuse |
| `mcp/` | Read-only Model Context Protocol server |
| `optional/` | Optuna, SHAP and Parquet |

Each file is intentionally standalone. Read its module docstring and install only the relevant optional packages before running it.
