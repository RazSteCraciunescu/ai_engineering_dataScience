# Statistics and mathematical foundations

## Scalars, vectors, matrices and tensors

A scalar is one number, a vector is an ordered sequence, a matrix has rows and columns, and a tensor generalizes to more dimensions. Embeddings are vectors that represent items such as text. Masks select positions that participate in a calculation.

## Mean versus median

The mean uses every magnitude and changes strongly when extreme values appear. The median depends on order and is more robust for right-skewed resolution time. The project reports both and uses category medians for selected imputations.

## Distributions

A normal or Gaussian distribution is symmetric. A uniform distribution has constant density over an interval. Operational durations are often right-skewed. Variance measures average squared deviation; standard deviation is its square root. Density describes relative concentration rather than count.

## Normalization and gradient descent

Min-max normalization maps values to a fixed interval. Standardization centers at zero with unit standard deviation. Gradient descent repeatedly moves parameters in the direction that reduces loss; its learning rate controls step size.
