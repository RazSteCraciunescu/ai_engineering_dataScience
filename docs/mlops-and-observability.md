# MLOps and observability

The repository stores data-quality reports, package versions, model metrics, model cards, a pipeline manifest and checksums. CI compiles code, runs tests and validates expected artifacts.

Optional examples distinguish experiment tracking (MLflow and W&B) from LLM/retrieval tracing (Langfuse). Production also needs a registry approval process, drift monitoring, alert ownership, retention rules, rollback and service-level objectives.
