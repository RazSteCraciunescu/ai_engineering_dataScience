# Transformers and LLMs

BERT is a bidirectional transformer encoder commonly adapted for understanding tasks. ALBERT reduces parameter duplication through sharing and factorized embeddings. RoBERTa changes BERT's training recipe. GPT-style models are autoregressive decoders that predict the next token and are naturally suited to generation.

These are architecture families, not quality guarantees. Data, evaluation, context boundaries, latency and operating constraints remain decisive.
